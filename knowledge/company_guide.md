# AI Communication Assistant — sample knowledge base

## Product overview
AI Communication Assistant helps users write emails, reply to emails, and ask general AI questions.

## Supported modes
- Write Email: create a new email from notes
- Reply to Email: generate a response to a pasted email
- Ask AI: answer questions, optionally using this knowledge base (RAG)

## Company communication guidelines
- Prefer clear, concise language
- Use a professional tone by default
- Never invent private customer facts
- Include a subject line for outbound emails
- End emails with a polite closing

## Example services
- Customer sync status updates
- Sales order sync progress reports
- Meeting follow-ups
- Pricing clarification emails
